موقع A2Z Media Agency (النسخة 2)
================================
index.html      الصفحة الرئيسية (افتحها بالمتصفح مباشرة)
css/style.css   كل التصميم والألوان (المتغيرات في أول الملف :root)
js/data.js      المحتوى كله: باقة المدرسين، العروض، الخدمات، الأرقام، الأسئلة، رسائل الواتساب، رقم الواتساب
js/render.js    بيبني الأقسام من data.js + ويدجت الواتساب
js/main.js      الحركات والريل والتفاعلات
images/         الصور

تعديل الأسعار والعروض: كله في js/data.js
- TEACHERS  : باقة المدرسين (السعر القديم/الجديد، المميزات)
- OFFERS    : باقي العروض (ضيف أو احذف أي سطر)
- QUICK     : رسائل الواتساب الجاهزة في الويدجت المثبت
- PHONE     : رقم الواتساب
- STATS     : أرقام تجريبية، عدّلها بالأرقام الحقيقية

الرفع: ارفع المجلد كله على أي استضافة (Netlify / Vercel / GitHub Pages) وخلي index.html في الجذر.
الخطوط محتاجة اتصال انترنت.
